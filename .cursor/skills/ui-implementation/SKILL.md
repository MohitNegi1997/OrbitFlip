# UI implementation

1. Read `docs/ARCHITECTURE.md`, `docs/PROJECT_STATE.md`, `docs/UI_UX_REQUIREMENTS.md`, and the approved screen spec/assets.
2. Stop if UI is still blocked or this screen is not approved.
3. Implement only that screen or component. Match the approved reference. Do not invent layout, icons, or copy.
4. Run the scene and capture a screenshot.
5. Report changed files. Stop. Do not commit. Do not start the next screen.
