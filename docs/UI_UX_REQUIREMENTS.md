# UI / UX Requirements

UI IMPLEMENTATION IS BLOCKED.

No final UI may be implemented until:

1. UI use cases are defined
2. screens are approved
3. screen states are approved
4. interaction rules are approved
5. responsive behavior is approved
6. required SVG assets are approved

Planned screens (not specified):

- Main Menu
- Modes
- Gameplay
- Pause
- Settings
- Leaderboard
- Skins
- Game Over / Results

Do not invent detailed requirements in this document until they are approved.
