# Decisions

## ADR-001

Feature-first Clean Architecture selected.

## ADR-002

Godot UI must remain separated from gameplay/domain rules.

## ADR-003

Cartoon Arcade is the initial visual theme.

## ADR-004

Theme system must support complete visual replacement later.

## ADR-005

SVG is the preferred format for suitable icons/UI vector assets.

## ADR-006

UI implementation requires screenshot approval before proceeding.
